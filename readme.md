# Crypto Price Telegram Bot

A Python-based Telegram bot that fetches and displays the latest cryptocurrency prices using the CoinMarketCap API.

## 📌 Features
- Retrieves the latest prices for Bitcoin (BTC) and Ethereum (ETH).
- Responds to the `/start` command with a welcome message and the user's chat ID.
- Responds to the `/prices` command with the latest cryptocurrency prices.

## 🛠️ Requirements
- Python 3.x
- A Telegram Bot Token (from BotFather)
- A CoinMarketCap API Key
- Required Python libraries: `python-telegram-bot`, `requests`

## 🚀 Installation

1. Clone this repository:
   ```sh
   git clone https://github.com/yourusername/crypto-telegram-bot.git
   cd crypto-telegram-bot
   ```

2. Install dependencies:
   ```sh
   pip install -r requirements.txt
   ```

3. Set your API credentials in the script:
   ```python
   TELEGRAM_BOT_TOKEN = "Your Telegram Bot Token"
   API_KEY = "Your CoinMarketCap API Key"
   ```

4. Run the bot:
   ```sh
   python bot.py
   ```

## 📌 Usage
- Start the bot by sending `/start` in Telegram.
- Retrieve cryptocurrency prices with `/prices`.

# Bot de Preços de Criptomoedas para Telegram

Um bot de Telegram desenvolvido em Python para buscar e exibir os preços mais recentes de criptomoedas usando a API do CoinMarketCap.

## 📌 Funcionalidades
- Obtém os preços mais recentes do Bitcoin (BTC) e Ethereum (ETH).
- Responde ao comando `/start` com uma mensagem de boas-vindas e o ID do chat do usuário.
- Responde ao comando `/prices` com os preços atualizados das criptomoedas.

## 🛠️ Requisitos
- Python 3.x
- Um Token de Bot do Telegram (obtido no BotFather)
- Uma Chave de API do CoinMarketCap
- Bibliotecas Python necessárias: `python-telegram-bot`, `requests`

## 🚀 Instalação

1. Clone este repositório:
   ```sh
   git clone https://github.com/seuusuario/crypto-telegram-bot.git
   cd crypto-telegram-bot
   ```

2. Instale as dependências:
   ```sh
   pip install -r requirements.txt
   ```

3. Defina suas credenciais da API no script:
   ```python
   TELEGRAM_BOT_TOKEN = "Seu Token do Bot do Telegram"
   API_KEY = "Sua Chave de API do CoinMarketCap"
   ```

4. Execute o bot:
   ```sh
   python bot.py
   ```

## 📌 Uso
- Inicie o bot enviando `/start` no Telegram.
- Obtenha os preços das criptomoedas com `/prices`.
